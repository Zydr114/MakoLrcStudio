# Mako LRC Studio

在浏览器里把歌词制作成带逐字／词时间的增强 LRC。Vue 3、TypeScript、Vite、mdui 2；音频、文字、编辑进度都在本机处理。生产发布只需要静态文件服务器。

## 本地运行

使用 Node.js 22.12 或更高版本：

```sh
npm ci
npm run dev
```

本机需要代理时：

```sh
npm ci --proxy=http://127.0.0.1:7897 --https-proxy=http://127.0.0.1:7897
```

## 制作一首歌

1. **导入**音频和歌词，或粘贴文字。支持 TXT、普通 LRC、尖括号增强 LRC；文件可选择 UTF-8、GB18030、Shift-JIS 预览。
2. **整理**：删除无关行，编辑文字，在光标处分句或合并下一句。批量替换、去空白及去括号内容先预览再应用。整理框中的换行会成为独立歌词行。
3. **逐行打轴**：第一次 Enter 播放，此后每次 Enter 记下一句起点。已有句首保留，可拖动或输入 `mm:ss.SSS` 修改。句首齐全且有效后进入逐字。
4. **逐字打轴**：中文及日语按完整可见字符，拉丁文字按词。Shift + 点击选择相邻单位后合并；单个单位可以拆分。第一次 Enter 播放，每次 Enter 记当前放大单位的起点，最后一次 Enter 记收尾并暂停。试听后手动进入下一句。
5. **导出**前检查全部时标；缺失或冲突会定位并提示。编辑进度可随时下载 JSON 备份。

| 按键（工作区获得焦点后） | 操作                                           |
| ------------------------ | ---------------------------------------------- |
| Enter                    | 开始／恢复播放；播放中记起点，最后一次记收尾   |
| Space                    | 播放／暂停                                     |
| Backspace                | 撤销刚才录点，回退 1 秒源音频时间并暂停        |
| R                        | 提前一秒试听当前句                             |
| Ctrl / Cmd + Enter       | 完成后进入下一句                               |
| Esc                      | 暂停；拖动过程中取消拖动                       |
| ← / →                    | 定位 1 秒；聚焦时标时微调 10ms，Shift 微调 1ms |
| Ctrl / Cmd + Z           | 撤销；加 Shift 重做                            |

输入框、按钮和输入法确认使用正常编辑行为。长按 Enter 不重复打点。重新打某个单位时，选择它并点击「从选中单位重打」，前面的时标保留。

## 草稿、音频与格式

- 每次编辑立即提交 IndexedDB，提交完成后显示「草稿已保存在本机」。刷新恢复当前草稿；音频不写入草稿，需要重新选择同一文件，工具会检查 SHA-256 摘要。
- 播放位置随暂停、定位及离开页面保存。浏览器清理站点数据会清除草稿；下载的 `.mako.json` 可独立恢复。保存失败时，界面会提示下载备份。
- 只保留一个当前草稿。制作下一首前可以下载备份，再在设置中新建项目。同一站点同时编辑多个窗口会共享草稿，建议一次使用一个窗口。
- 音频由 Web Audio 解码一次并播放，WaveSurfer 只画同一份数据生成的波形。0.75×／0.5× 会降低音高；录点始终使用源音频时间。补偿默认 0ms，正值提前新记录，已有记录使用整体平移。
- 日语按字形切分，可以手工合并「きゃ」「今日」；汉字读音和音节边界由用户判断。
- 采用 `[句首]<单位起点>文字…<收尾>`，UTF-8、三位小数。正 `offset` 表示提前，导入时应用后删除；无效 offset 明示忽略，负时标需要修正。
- 第一版适合单轨顺序演唱。时标严格递增，收尾不能越过下一句；合唱重叠、同时间翻译行需在整理阶段处理。歌词中的静音间隔不单独编码。
- 末尾空时间标签被部分播放器忽略，最终播放效果取决于目标播放器。毫秒存储精度不代表人工或音频设备的毫秒精度。
- 音频整段解码消耗内存，优先普通单曲；格式支持依浏览器而定。解码失败会保留编辑进度。

示例：

```lrc
[ti:今日]
[00:12.340]<00:12.340>今<00:12.620>日<00:12.940>も<00:13.410>
```

## 静态发布

```sh
npm run build
npm run preview -- --port 4173
```

将 **dist 目录中的内容**复制到服务器站点目录，例如 `/lrc/`。入口访问 `/lrc/` 或 `/lrc/index.html`，包含 `assets/` 和 `favicon.svg`。资源路径是相对路径，无 URL 路由，无需 SPA 重写规则，也没有后端 API。

线上使用 **HTTPS**，本地使用 localhost／127.0.0.1。音频摘要和唯一标识需要浏览器的安全环境；直接打开 `file://` 不适合作为运行方式。站点域名或端口改变会使用另一份浏览器存储。

Nginx 等常规静态服务器应正确发送 HTML、JavaScript、CSS、SVG MIME 类型。替换发布时整套更新 index.html 和 assets；入口页面避免长期缓存，带哈希的 assets 可以长期缓存。无需 CORS 音频服务，用户直接选本地文件。

## 验证与结构

```sh
npm test
npm run build
npx playwright install chromium firefox
npm run test:e2e
```

`npm run test:e2e:all` 加上 WebKit，需要相应浏览器运行依赖。Playwright 使用生产 dist，验证普通文件服务器的 `/mako/` 子目录部署，不依赖开发服务器路由回退。

| 目录                           | 职责                                               |
| ------------------------------ | -------------------------------------------------- |
| `src/domain`                   | 格式、Unicode 切分、数据约束、编辑命令、撤销、备份 |
| `src/audio`                    | 共享解码数据、播放和输出时钟映射                   |
| `src/state`                    | 打轴状态机、四阶段流程、草稿持久化                 |
| `src/views` / `src/components` | 工作区、波形时标、精确输入及 mdui 适配             |
| `tests/unit` / `tests/e2e`     | 数据、状态机及生产浏览器流程                       |

实现及实际验收记录见 [PLAN.md](PLAN.md)。当前自动验证范围是 Chromium、Firefox；Safari、真实输入法候选窗口、实际耳机／蓝牙输出延迟及人工听感仍需真实设备验收。
