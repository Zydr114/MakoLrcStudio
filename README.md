# MakoLrc Studio

在浏览器里把歌词制作成带逐字／词时间的增强 LRC。

## 这个项目做什么

给需要自己做逐字歌词的人一个不用安装软件的工具：导入歌词文本，一边听音频一边打轴，导出增强 LRC。

- **纯本地处理**：音频、歌词和编辑进度都在浏览器里处理，不上传，没有后端、账号或网络请求。
- **文本先行**：整理、分句和改错不依赖音频，音频可以在开始打轴前再选。
- **两步打轴**：先定每句起点，再在句内切分字／词、补逐字时间与收尾。
- **随时回改**：「文本处理／逐行打轴／逐字打轴」是共享同一份歌词、音频、定位和撤销历史的三个页签，可自由来回切换。
- **可独立备份**：编辑进度即时写入浏览器本地存储，也能随时下载 `.mako.json` 备份。
- **静态发布**：构建产物是一组静态文件，放到任意静态服务器即可，无需 SPA 重写规则。

## 使用方法

### 制作一首歌

1. **导入歌词**文件或粘贴文字。音频可在此时选择，也可整理后加载。支持 TXT、普通 LRC、尖括号增强 LRC；文件可选择 UTF-8、GB18030、Shift-JIS 预览。
2. **整理**：删除无关行，编辑文字，在光标处分句或合并下一句。批量替换、去空白及去括号内容先预览再应用。整理框中的换行会成为独立歌词行。
3. **逐行打轴**：第一次 Enter 播放，此后每次 Enter 记下一句起点。已有句首保留，可拖动或输入 `mm:ss.SSS` 修改。点击「编辑／拆分」，放置光标后可直接拆句。
4. **逐字打轴**：中文及日语按完整可见字符，拉丁文字按词。「编辑／拆分」支持在光标处拆句或拆字／词；「调整切分」可点击字符间隙添加分隔线、拖动移动、Delete 移除。应用一次可撤销，取消不改项目。已有时间按原文位置保留，新增位置待打轴。第一次 Enter 播放，每次 Enter 记当前放大单位的起点，最后一次 Enter 记真实收尾并暂停；补打缺失项保留后方时标。试听后手动进入下一句。
5. **试听与导出**：波形色块显示实际区间，当前行预览实时跟随音频，拖动与合法输入草稿立即可见。可循环试听本行、选中单位或边界附近，整曲试听按歌词定位。导出前检查全部时标；缺失或冲突会定位并提示。编辑进度可随时下载 JSON 备份。

切换页签时会暂停并取消未应用草稿，保留当前行及定位。改变正文会保留句首，清除该行逐字时间和收尾，其余行不受影响。未改文字的拆句优先复用已有时间边界；在单位内部拆分会产生待补点，不估算时间。

打轴页的播放控制位于波形容器内，并提供 mdui 全曲进度滑块：点击波形空白或拖动进度条都能定位，「定位选中」回到当前句／单位起点。播放头、预览、色块与源时间共用播放时钟；歌词列表分别标出选中行和正在播放行。

### 快捷键

工作区获得焦点后：

| 按键               | 操作                                           |
| ------------------ | ---------------------------------------------- |
| Enter              | 开始／恢复播放；播放中记起点，最后一次记收尾   |
| Space              | 播放／暂停                                     |
| Backspace          | 撤销刚才录点，回退 1 秒源音频时间并暂停        |
| R                  | 试听当前句，包含前后上下文                     |
| Ctrl / Cmd + Enter | 完成后进入下一句                               |
| Esc                | 暂停；拖动过程中取消拖动                       |
| ← / →              | 定位 1 秒；聚焦时标时微调 10ms，Shift 微调 1ms |
| Ctrl / Cmd + Z     | 撤销；加 Shift 重做                            |

输入框、按钮和输入法确认使用正常编辑行为。长按 Enter 不重复打点。普通试听不启动录点；首次／恢复 Enter 只播放。重新打某个单位时，选择它并点击「从选中单位重打」，此前的时标保留，选中及后方时标和收尾清空；补打切分产生的缺失项会保留后方锚点与已有收尾。

波形边界可拖动，松手提交一次，Esc 取消；中间单位终点与下一起点共用一个边界。缩放后可横向滚动、拖动全曲概览范围、返回播放头或调整波形高度。普通 LRC 的句子色块是参考范围，不能当作真实句尾。默认预览检查起点，均匀填色不代表组内每字都有时间点。

### 草稿、音频与格式

- 每次编辑立即提交 IndexedDB，提交完成后显示「草稿已保存在本机」。刷新恢复当前草稿；音频不写入草稿，需要重新选择同一文件，工具会检查 SHA-256 摘要。
- 播放位置随暂停、定位及离开页面保存。浏览器清理站点数据会清除草稿；下载的 `.mako.json` 可独立恢复。保存失败时，界面会提示下载备份。
- 只保留一个当前草稿。制作下一首前可以下载备份，再在设置中新建项目。同一站点同时编辑多个窗口会共享草稿，建议一次使用一个窗口。
- 音频由 Web Audio 解码一次并播放，WaveSurfer 只画同一份数据生成的波形。0.75×／0.5× 会降低音高；录点始终使用源音频时间。补偿默认 0ms，正值提前新记录，已有记录使用整体平移。
- 日语按字形切分，可以手工合并「きゃ」「今日」；汉字读音和音节边界由用户判断。
- 采用 `[句首]<单位起点>文字…<收尾>`，UTF-8、三位小数。正 `offset` 表示提前，导入时应用后删除；无效 offset 明示忽略，负时标需要修正。
- 第一版适合单轨顺序演唱。时标严格递增，收尾不能越过下一句；合唱重叠、同时间翻译行需在整理阶段处理。歌词中的静音间隔不单独编码。
- 末尾空时间标签被部分播放器忽略，最终播放效果取决于目标播放器。毫秒存储精度不代表人工或音频设备的毫秒精度。
- 音频整段解码消耗内存，优先普通单曲；格式支持依浏览器而定。解码失败会保留编辑进度。

示例：

```lrc
[ti:今日]
[00:12.340]<00:12.340>今<00:12.620>日<00:12.940>も<00:13.410>
```

## 开发

### 环境与依赖

需要 Node.js 22.12 或更高版本。

| 用途   | 依赖                                                                |
| ------ | ------------------------------------------------------------------- |
| 运行时 | Vue 3、mdui 2（Material You Web Components）、WaveSurfer.js         |
| 构建   | Vite、TypeScript、vue-tsc、@vitejs/plugin-vue                       |
| 测试   | Vitest（单元）、Playwright（Chromium／Firefox 端到端）              |
| 其他   | Prettier（格式）、clrc（端到端测试里对照解析增强 LRC）、@types/node |

版本以 `package.json` 与 `package-lock.json` 为准。

### 常用命令

```sh
npm ci                                  # 按 package-lock.json 安装
npm run dev                             # 开发服务器（127.0.0.1）
npm run build                           # vue-tsc 类型检查 + 生产构建到 dist/
npm run preview                         # 预览构建产物
npm test                                # 单元测试（Vitest）
npx playwright install chromium firefox # 首次运行端到端测试前安装浏览器
npm run test:e2e                        # 端到端测试（Chromium、Firefox）
npm run test:e2e:all                    # 端到端测试再加 WebKit，需要相应运行依赖
npm run format                          # Prettier 格式化
```

端到端测试跑生产 `dist/`，并另外用普通文件服务器的子目录部署验证相对资源路径，不依赖开发服务器的路由回退。当前自动验证范围是 Chromium、Firefox；Safari、真实输入法候选窗口、实际耳机／蓝牙输出延迟及人工听感仍需真实设备验收。

### 构建与发布

```sh
npm run build
npm run preview -- --port 4173
```

将 **dist 目录中的内容**复制到服务器站点目录，例如 `/lrc/`。入口访问 `/lrc/` 或 `/lrc/index.html`，包含 `assets/`、`favicon-32.png`、`favicon-48.png` 与 `apple-touch-icon.png`。资源路径是相对路径，无 URL 路由，无需 SPA 重写规则，也没有后端 API。

线上使用 **HTTPS**，本地使用 localhost／127.0.0.1。音频摘要和唯一标识需要浏览器的安全环境；直接打开 `file://` 不适合作为运行方式。站点域名或端口改变会使用另一份浏览器存储。

Nginx 等常规静态服务器应正确发送 HTML、JavaScript、CSS、SVG MIME 类型。替换发布时整套更新 index.html 和 assets；入口页面避免长期缓存，带哈希的 assets 可以长期缓存。无需 CORS 音频服务，用户直接选本地文件。

### 目录结构

| 目录                           | 职责                                               |
| ------------------------------ | -------------------------------------------------- |
| `src/domain`                   | 格式、Unicode 切分、数据约束、编辑命令、撤销、备份 |
| `src/audio`                    | 共享解码数据、播放和输出时钟映射                   |
| `src/state`                    | 打轴状态机、共享编辑视图、草稿持久化               |
| `src/views` / `src/components` | 工作区、波形时标、精确输入及 mdui 适配             |
| `src/assets/brand`             | 页头品牌标、首页字标与 README 用原始分辨率字标     |
| `public`                       | 标签页图标与苹果触屏图标（固定文件名，不发哈希）   |
| `tests/unit` / `tests/e2e`     | 数据、状态机及生产浏览器流程                       |

### 品牌资源

`scripts/build-brand-assets.sh <含源图的目录>` 从源图 `MakoLrcStudio-Main.png`（宽字标）与 `MakoLrcStudio-Logo.png`（方徽标）生成页内图片、标签页图标与 README 字标：生成时裁掉透明边、按 PNG 无损导出，源图本身不纳入仓库。页内图片按 CSS 像素的 3 倍导出，`wordmark-full.png` 保留原始分辨率供 README 使用。默认主题色 `#01cff0` 取自字标主色青，可在设置里自行修改。
