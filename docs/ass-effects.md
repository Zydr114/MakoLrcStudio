# ASS 特效预设

2026-10-26 确认：提供整套预设与强度、特效色微调，保留 HTML/CSS 示意预览；真实效果以 libass 渲染验收。保持纯静态、本地处理，不引入用户脚本或完整 ASS 样式引擎。

## 实施步骤

1. 样式模型、兼容与结构化导出事件：完成。ASS 相关单元测试 22 项通过，默认输出的原有坐标、填色和源注释断言保持通过。
2. 静态质感：柔光、霓虹、立体描边。
3. 动态预设：柔和浮入、逐词弹跳、流光扫过、星屑粒子；确定性生成、预算保护。
4. 预设卡片、强度、颜色、示意动画与导出摘要。
5. 完整回归、真实渲染、性能记录与生产构建。

原样预设保持现有视觉；版式、字体和歌词颜色独立。新字段写入工程与 `; mako-style:`，旧数据默认原样，未知预设回退。装饰事件标记 `fx`，卡拉 OK 源保持不变。

注音减弱质感，整句进出场同步，弹跳以完整注音组为单位；和声不产生粒子；翻译与罗马音只保留描边与淡入淡出。前奏和双行预告不提前触发演唱特效。

粒子：每单位最多 3 个，同时最多 48 个；额外事件最多 30,000 条，超出时整份回退柔光并提示。所有空间参数随分辨率缩放。
