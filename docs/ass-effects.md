# ASS 特效预设

2026-10-26 实现。保持纯静态、浏览器本地处理；采用整套预设与少量微调，未引入用户脚本或完整 ASS 样式引擎。

## 使用与行为

入口：导出 → ASS → 编辑样式。版式、字体、字号、正文颜色独立保留；特效提供轻／中／强及颜色（默认跟随声部色）。「原样」保持原有排版、填色和淡入淡出。左侧是 HTML/CSS 示意，可播放、暂停、重播、切换深浅背景；减少动态效果时默认暂停，关闭弹窗即卸载计时器。

| 预设 ID   | 名称     | 实际 ASS 行为                                        |
| --------- | -------- | ---------------------------------------------------- |
| none      | 原样     | 现有填色与淡入淡出                                   |
| soft      | 柔光     | 清晰正文下方的模糊描边                               |
| neon      | 霓虹     | 宽窄两层光晕，真实演唱开始后增强                     |
| outline   | 立体描边 | 外层彩色轮廓与偏移阴影                               |
| float     | 柔和浮入 | 各文字层同步轻微上浮进入，淡出离开                   |
| bounce    | 逐词弹跳 | 当前单位的轮廓轻微上弹、缩放、回落，保留正文原始填色 |
| sweep     | 流光扫过 | 当前单位内的高亮窄带，矩形裁剪动画                   |
| particles | 星屑粒子 | 当前单位附近的稀疏矢量光点，散开淡出                 |

- 正文稳定清晰；注音质感减弱、弹跳整组配对，不按读音音节反复弹跳。轮廓强调不会覆盖其原始逐音节填色。
- 和声使用减弱质感及同步整句进场，不产生粒子；翻译与罗马音保持描边和淡入淡出。
- 前奏圆点与双行预告保留原语义，逐词强调由真实起点触发；明确终点形成的停顿不会被填色压缩。
- 辉光与动态预设增加少量层间留白，所有空间参数随分辨率缩放。过长正文会提示缩小字号或拆行，不自动改字、换行或改时间轴。
- 粒子每单位最多 3 个，全局同时最多 48 个，终点后不再发射；单个光点最多存活 450ms，路径约束在画面内，随机序列可复现。
- 装饰事件最多 30,000 条。预估超额时整份回退柔光并提示，工程设置保留；超长工程的柔光同样遵守上限，剩余歌词保留清晰正文。

## 数据与兼容

`AssStyle.effects` 为 `{ preset, intensity, color }`，颜色为空表示跟随声部色。旧工程、旧 ASS 缺少该字段或未知预设时回退原样；归一化复制嵌套设置，取消、默认值与不同工程不共享可变对象。设置通过编辑命令保存，支持撤销、本地草稿、工程备份和 `; mako-style:` 回读。

排版先产生结构化事件与共享坐标，再由特效模块装饰并序列化。所有额外事件标记 `fx`；原卡拉 OK Comment 源不变，翻译与罗马音各保留一条回读正文。导入忽略装饰事件。

未增加运行时依赖或网络服务。采用常用 ASS 标签，以 FFmpeg/libass 为实际渲染验收基准；HTML/CSS 不承诺与最终 ASS 逐像素一致，VSFilter、移动播放器等尚未独立验收。字体度量与播放端字体必须匹配。

## 实施与验证

1. **模型与导出结构完成**：新字段、默认值、备份兼容、结构化序列化；原有默认坐标与时间输出断言通过。
2. **静态质感完成**：柔光、霓虹、双描边阴影；真实浏览器字体度量 + libass 帧检查。
3. **动态预设完成**：4 套动态、注音配对、确定性生成、粒子与事件预算。回归覆盖短音节、停顿、前奏、下一句预告、并发、路径边界和整体回退。
4. **界面完成**：预设卡片、强度、颜色、示意动画与摘要。端到端覆盖全部预设下载、取消、撤销、草稿恢复、减少动态、390px 无水平溢出；修复连续选择同一导出格式时 mdui 菜单选中值重置的重入问题。
5. **渲染与交付验收**：完整数字和环境记录见 `ass-effects-validation.json`。真实渲染样例包含 8 套预设在三种版式下的输出、720p/4K 抽查、最大字号/描边、极短音节、前奏与预告。全部预设有深浅背景的动态短片；密集歌词另记录导出与渲染吞吐。

可再生证据（需本机安装 FFmpeg/libass、Noto Sans CJK JP、Python Pillow 及 Playwright Chromium）：

```sh
node scripts/ass-effects-samples.mjs /tmp/mako-ass-effects
python scripts/render-ass-effects.py /tmp/mako-ass-effects
```

首条命令使用临时 Vite 服务、Chromium 和实际字体度量，结束时关闭服务与浏览器；第二条产生 PNG、MP4、对比图和渲染时间。未把浏览器示意当作真实 ASS 渲染结果。

本机性能记录为合成样本，不能代表所有设备。密集样本为 120 行、2,160 个时间单位、约 4 分钟歌词，导出整份文件，视频测量前 30 秒的 1080p/30fps 渲染（含 H.264 编码）；采用 2 个 FFmpeg 线程、同时 2 个任务。

### 最终检查结果

- `npm test`：16 个文件、143 项通过。
- `npm run test:e2e`：Chromium / Firefox 共 112 项通过。
- `npm run build`、改动文件 Prettier 检查与 `git diff --check` 通过。
- 40 份 ASS 均经 libass 渲染，生成 24 段视频，核对深浅背景、注音配对和逐帧动效；桌面/移动示意界面已检查。
- 验收文件在 `/tmp/mako-ass-effects-final/`：`contact-dark.png` / `contact-light.png` 为对比图，`motion-sequence.png` 为逐帧检查，`*-dark.mp4` / `*-light.mp4` 为动态样片。
